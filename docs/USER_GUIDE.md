# 고객 사용 가이드

## 1. 서비스 개요

PDF 문서 변환 서비스는 PDF 파일을 업로드해 수정 가능한 DOCX 파일로 변환하는 웹 서비스다.

현재 MVP에서는 텍스트가 포함된 일반 PDF를 DOCX로 변환하는 기능을 우선 제공한다. 단순 표는 DOCX 표로 변환한다. 1장 PDF는 변환 결과도 가능한 한 1장 안에서 해결되도록 편집 우선 규칙을 적용한다. 스캔 이미지 기반 PDF의 OCR 변환과 HWP 변환은 이후 단계에서 확장될 예정이다.

## 2. 접속 주소

개발 환경 기준 접속 주소는 다음과 같다.

- 웹 화면: `http://localhost:13801`
- 백엔드 API: `http://localhost:13800`

고객은 일반적으로 웹 화면 주소만 사용하면 된다.

## 3. 사용 전 준비사항

변환하려는 파일은 다음 조건을 만족해야 한다.

- 파일 형식: PDF
- 권장 문서: 텍스트 선택이 가능한 일반 PDF
- 현재 변환 결과 형식: DOCX
- 변환 지원 범위: 텍스트, 단순 표, 1장 PDF의 1장 결과 유지

현재 버전에서는 다음 문서의 변환 품질이 제한될 수 있다.

- 스캔 이미지로만 구성된 PDF
- 복잡한 표, 다단 편집, 도장, 서명, 이미지 배치가 많은 PDF
- 암호가 걸려 있거나 손상된 PDF

현재 별도 보정이 적용된 샘플 양식:

- `배달의민족 회원탈퇴 요청서.pdf`
- PDF 내부 한글 텍스트 추출값이 깨지는 문서이므로, 양식 구조를 편집 가능한 DOCX 템플릿으로 재구성한다.
- 결과 DOCX에는 입력 가능한 정보주체/법적보호자 표, 유의사항 문단, 요청일/요청인 영역이 포함된다.
- 정보주체와 법적보호자 영역은 원본처럼 세로 병합된 셀로 제공된다.
- 유의사항은 제목 셀과 본문 셀로 분리된다.
- 원본 PDF가 1장이므로 변환 결과도 Microsoft Word와 LibreOffice Writer 기준 1장으로 유지된다.

## 4. PDF 변환 절차

### 4.1 사이트 접속

브라우저에서 웹 화면 주소로 접속한다.

```text
http://localhost:13801
```

화면 상단에 `PDF 문서 변환` 제목이 보이면 정상 접속된 상태다.

### 4.2 PDF 파일 선택

1. `PDF 파일` 입력 영역에서 파일 선택 버튼을 누른다.
2. 변환할 PDF 파일을 선택한다.
3. 선택한 파일명이 화면에 표시되는지 확인한다.

### 4.3 변환 시작

1. `변환 시작` 버튼을 누른다.
2. 화면 메시지가 `변환 작업을 생성하는 중입니다.`로 변경된다.
3. 작업 생성이 완료되면 `변환 작업이 생성되었습니다.` 메시지가 표시된다.

### 4.4 작업 상태 확인

오른쪽 `작업 상태` 영역에서 변환 상태를 확인한다.

상태 값은 다음과 같다.

- `작업 없음`: 아직 변환 작업을 생성하지 않은 상태
- `PENDING`: 변환 작업이 생성되어 대기 중인 상태
- `PROCESSING`: 변환이 진행 중인 상태
- `COMPLETED`: 변환이 완료되어 다운로드 가능한 상태
- `FAILED`: 변환이 실패한 상태

상태가 바로 바뀌지 않으면 `상태 갱신` 버튼을 눌러 최신 상태를 확인한다.

### 4.5 결과 다운로드

상태가 `COMPLETED`가 되면 `다운로드` 버튼이 활성화된다.

1. `다운로드` 버튼을 누른다.
2. 변환된 DOCX 파일을 저장한다.
3. Word, 한글, LibreOffice Writer 등 DOCX를 열 수 있는 프로그램에서 파일을 확인한다.

## 5. 오류 상황별 조치

### 5.1 PDF 파일을 선택하라는 메시지가 표시되는 경우

PDF 파일을 선택하지 않고 `변환 시작`을 누른 상태다.

조치:

- PDF 파일을 먼저 선택한 뒤 다시 `변환 시작`을 누른다.

### 5.2 변환 작업 생성에 실패한 경우

파일 업로드 또는 서버 처리 중 문제가 발생한 상태다.

조치:

- 파일 확장자가 `.pdf`인지 확인한다.
- 파일이 열리는 정상 PDF인지 확인한다.
- 다른 PDF 파일로 다시 시도한다.
- 문제가 반복되면 관리자에게 파일명과 발생 시각을 전달한다.

### 5.3 상태가 FAILED인 경우

서버가 PDF를 읽거나 DOCX로 변환하는 중 실패한 상태다.

조치:

- PDF가 암호화되어 있는지 확인한다.
- 스캔 이미지 PDF인지 확인한다.
- 텍스트 선택이 가능한 PDF로 다시 시도한다.
- 문제가 반복되면 관리자에게 원본 파일과 오류 메시지를 전달한다.

### 5.4 다운로드 버튼이 비활성화된 경우

변환이 아직 완료되지 않은 상태다.

조치:

- `상태 갱신` 버튼을 눌러 상태를 다시 확인한다.
- 상태가 `COMPLETED`로 바뀐 뒤 다운로드한다.

## 6. 현재 버전의 제한사항

- 변환 대상 형식은 DOCX만 지원한다.
- OCR은 아직 지원하지 않는다.
- HWP 직접 변환은 아직 지원하지 않는다. LibreOffice 기반 `.hwp` 내보내기는 export filter가 없어 실패하는 것으로 확인되었다.
- 단순 표는 DOCX 표로 변환되지만, 복잡한 병합 셀이나 다단 표는 완전히 복원되지 않을 수 있다.
- 다중 페이지 또는 레이아웃 참고가 필요한 문서는 원본 페이지 미리보기 이미지가 DOCX에 포함될 수 있다.
- 1장 PDF의 편집 우선 변환에서는 페이지 수 증가를 막기 위해 원본 전체 미리보기 이미지를 기본 포함하지 않는다.
- 개별 이미지 객체를 원본 위치 그대로 편집 가능한 객체로 분리하는 기능은 아직 지원하지 않는다.
- 변환 결과는 편집 가능한 텍스트/표를 우선 제공하고, 필요 시 원본 페이지 미리보기를 함께 제공한다.
- PDF 내 한글 텍스트 매핑이 깨지는 일부 양식은 별도 템플릿 보정이 필요하다.
- Word와 LibreOffice의 글꼴 및 줄바꿈 계산 차이로 일반 문서의 페이지 수가 다르게 표시될 수 있다.

## 7. 권장 사용 방식

- 문서 내용을 수정해야 하는 일반 PDF를 우선 사용한다.
- 스캔본보다 텍스트 선택이 가능한 PDF를 사용한다.
- 변환 후 DOCX 파일에서 문단, 줄바꿈, 표 형태를 직접 확인한다.
- 중요한 문서는 변환 결과를 원본과 비교한 뒤 사용한다.

## 8. 관리자에게 전달할 정보

문제가 발생하면 다음 정보를 함께 전달하면 원인 파악이 빠르다.

- 사용한 PDF 파일명
- 변환 시도 시각
- 화면에 표시된 상태 값
- 화면에 표시된 오류 메시지
- 브라우저 종류
- 파일이 스캔본인지 텍스트 PDF인지 여부
